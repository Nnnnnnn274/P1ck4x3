Eagle Dynamic Notifications

Native SwiftUI/UIKit/Core Image port of the capsule, droplet and expanding
notification interaction in rit3zh/expo-dynamic-notifications:
https://github.com/rit3zh/expo-dynamic-notifications
Reference revision: 5de059a5cbefbe28c14efbe785166665a7c70bc5

Eagle uses its own native implementation, with no Expo, React Native, Skia,
Reanimated, fonts, avatars or network dependencies from that project.
The reference repository's license is reproduced below.

Ported reference logic: get-notification-layout.ts,
build-notification-geometry.ts, build-goo-matrix.ts, neck-profile.ts,
notification.consts.ts, gooey.tsx, springUtils.ts and the enter/return timeline.
