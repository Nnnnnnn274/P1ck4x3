# Eagle 1.0.5 (92)

Stable update to the public 1.0.4 release. The IPA is unsigned; sign it with your usual personal-device installation method.

## What changed

- Island and Dock Galleries have more consistent Live, Static and Saves controls, smoother focused previews, and quarter-point artwork positioning. Aura Studio also exposes Island and Dock position controls.
- The Access/Customize bar uses the native translucent tab surface. Eagle result notifications appear after an action without pushing the screen down, and repeated results replace the previous notice promptly.
- Prepare retains its animated rainbow progress, now has a green action button, and transitions into Ready smoothly.
- Settings and Laboratory Tools have distinct roles. The Updates screen reflects the 1.0.5 changes.
- Cards and related light action buttons now use dark text for legibility. Duck Mood, Blue Screen and Walking Flame were removed only from Island Gallery; Dock Gallery retains them.
- Gallery media and operation-lifetime checks were tightened without changing the established Prepare, theme Apply, Hide Dock or Aura execution paths.

## Compatibility and limits

- Prepare: limited testing on iOS 16.7.2; supported matrix includes iOS 17.0–18.7.1 and 26.0–26.0.1. The compatibility screen remains authoritative for each device.
- Live Island and Dock changes are limited to the verified iOS 17/18 SpringBoard routes. Some visual presentations can differ by iOS version.
- Hide Dock must be reapplied after a full device restart. Test one system modification at a time and keep a backup.
